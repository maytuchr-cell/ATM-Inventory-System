ติดตามอะไหล่ค้างที่ช่าง
ใครยังไม่กดรับอะไหล่ ใครค้างคืนเกินกำหนด และงานที่ค้างอยู่ฝั่ง Admin เอง
อะไหล่ควรถึงมือช่างตาม SLA แล้ว แต่ช่างยังไม่กดยืนยันรับของ — อาจลืมกด หรือของยังไม่ถึงจริง
ช่าง / เบอร์โทรเลยกำหนดอะไหล่ใบเบิก / TicketSLA · ควรถึงเมื่อ
นับทุกใบเบิกที่รับของแล้วแต่ยังไม่คืน ยกเว้นใบที่ระบุว่า "เก็บไว้ใช้" (Keep)
ช่าง / เบอร์โทรเกินกำหนดอะไหล่ใบเบิก / Ticketรับของเมื่อ · ถือมาแล้ว
ช่างที่ถืออะไหล่ค้างอยู่ทั้งหมด (ยังไม่คืน) — ใช้ตัดสินว่าควรตามใครก่อน
ช่าง / เบอร์โทรจำนวนใบเบิกค้างเกินกำหนดจำนวนชิ้นค้างนานสุด
เทียบจำนวนที่ช่างเบิกไปกับที่คืนแล้ว (ไม่รวมใบประเภท "เก็บไว้ใช้")
ช่าง / เบอร์โทรสถานะความคืบหน้าเบิกคืนแล้วถึงคลังยังขาด
งานที่รอ Admin ดำเนินการ ไม่ใช่รอช่าง — รออนุมัติ หรืออนุมัติแล้วแต่ยังไม่ได้ส่งเมลแจ้ง DHL

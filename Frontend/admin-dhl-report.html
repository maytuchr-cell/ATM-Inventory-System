ระบบจะดำเนินการดังนี้:
  • ลบประวัติการนำเข้า Daily Report ทั้งหมด
  • รีเซ็ตยอดสต็อกอะไหล่ทุกรายการเป็น 0
  • ล้างประวัติการเคลื่อนไหวสต็อก ที่เกิดจากการนำเข้า
  • ล้างทะเบียน S/N ที่เกิดจากการนำเข้า
  • รีเซ็ตสถานะใบเบิกรับคืน กลับสู่สถานะก่อนนำเข้า
